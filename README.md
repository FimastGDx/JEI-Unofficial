# JEI-Unofficial

Unofficial back-port of [JustEnoughItems](https://github.com/mezz/JustEnoughItems) to
**Minecraft 1.21.4 / Fabric**.

The actual code is on the
[`1.21.4-fabric-backport`](https://github.com/FimastGDx/JEI-Unofficial/tree/1.21.4-fabric-backport)
branch, which is the default branch of this repository. This `main` branch is a leftover from
repository creation and contains nothing else.

Not affiliated with mezz, not an official JEI release, and not runtime-tested in Minecraft.
JEI is © mezz and MIT licensed — see
[LICENSE.txt](https://github.com/FimastGDx/JEI-Unofficial/blob/1.21.4-fabric-backport/LICENSE.txt)
on the back-port branch.

> Неофициальный бэкпорт JEI на Minecraft 1.21.4 (Fabric). Код — в ветке
> `1.21.4-fabric-backport`.
